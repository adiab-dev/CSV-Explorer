# Development Journal

## 1. Project Overview

**Project:** CSV Explorer

**Description:** A web application for uploading, exploring, filtering, analyzing, and visualizing CSV datasets.

**Motivation:**

I always felt that the task of looking through or editing CSV files was daunting, especially with how much skill it takes to use and manipulate the different spreadsheet software, and how they are all often terrible to look at in terms of UI. This project solves this problem for me. I can now look through and edit CSV files in a friendly interface with very easy and simple steps.

**Initial Goals:**

- CSV Upload to the program: allow CSV files to be checked for their size, uploaded and received by the program
- Interactive Data table: Display CSV contents in a table, with the ability to sort columns in ascending or descending order, navigate through large data sets through pagination, and handling missing values
- Automatic Statistics: Total number of rows and columns, Average numerical values of each numerical column or row, Minimum and Maximum values of each numericall column or row and Count of missing values.
- Data Visualisation: Select column(s) to visualise, generate bar charts, generate pie charts, generate line charts and Update charts when data changes
- Data Filtering: Search through rows, Filter by column values, Filter numerical columns using minimum and maximum values, reset filters
